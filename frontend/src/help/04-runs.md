# Прогоны

Прогон - запуск набора тестов на окружении. Результаты прогона записываются в репозиторий результатов проекта, портал
показывает их и строит статистику. Прогоны, запущенные не из портала (из консоли), тоже попадают сюда.

## Запуск прогона

Кнопка «Запустить прогон» на «Обзоре» и в «Задачах» (разработчик, тестировщик, администратор).

| Поле | Что это |
|---|---|
| Набор | Набор тестов из репозитория тестов: смоук, функциональные, безопасность и т. п. |
| Окружение | Только окружения, разрешённые в конфигурации установки: промышленный стенд из портала не запустить |
| Ветка тестов | Из какой ветки репозитория тестов брать тесты, обычно `main` |
| Метки | Запустить только тесты с метками (через пробел) |
| Группы безопасности | Группы проверок безопасности `sg-...` |
| Какие тесты запустить | Весь набор, выбор существующих тестов из списка или фильтр по названию. Поиск только сужает список; отметки сохраняются. Фильтр принимает части названий по одной на строку; пустой фильтр запускает весь набор |
| Разрушающие тесты | Тесты, которые могут заблокировать учётки или изменить данные стенда. Только тестировщик и администратор, только явной отметкой |

Наборы показаны деревом модулей и папок: изначально все ветки свёрнуты. Раскройте нужный модуль и отметьте наборы или используйте «Раскрыть всё». Числа у папки показывают количество выбранных наборов и общее число доступных наборов в ней. Сворачивание сохраняет выбор. Можно выбрать не более 20 наборов; чтобы заменить набор при достижении лимита, снимите с него отметку. При смене проекта выбор сбрасывается и ветки сворачиваются.

Список существующих тестов показан деревом папок, файлов и классов. Ветки можно раскрывать отдельно или все сразу; при поиске пути к совпадениям раскрываются автоматически. Числа у ветки показывают количество выбранных тестов и общее число тестов в ней. Отметки сохраняются при сворачивании и поиске, но сбрасываются при смене проекта, набора или ветки. Можно выбрать не более 500 тестов.

При выборе существующих тестов gate запускается дополнительно, если настроен. Выбранный тест pytest запускается со всеми вариантами параметров. Метки и группы также ограничивают запуск.

## Как читать прогон

- **Итог** - сколько тестов прошло из скольких; упавшие - красной меткой.
- **gate** - короткий смоук в начале прогона. Не прошёл - остальные тесты не запускаются, стенд считается нерабочим.
- **Отчёт** - сводка прогона с разбором упавших и найденными багами; **Allure** - подробный отчёт по каждому тесту.
- Для среза по всему модулю, нескольким прогонам и покрытию используйте отдельный раздел «Сводки».
- **Сравнение** двух прогонов показывает, что починилось и что сломалось.
- Прогон из портала помечен как запущенный порталом (кто и номер задачи), в отчёте - что было развёрнуто на стенде:
  версии и коммиты компонентов.
