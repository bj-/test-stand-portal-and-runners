# Начало работы

Портал собирает в одном месте всё, что нужно для тестирования: стенды, запуск прогонов, результаты, отчёты, баги и
статистику. Сами тесты пишутся и хранятся вне портала, в репозитории тестов проекта.

## Первый вход

1. Получите у администратора логин и **разовый пароль**.
2. Если браузер предупреждает о сертификате - один раз поставьте сертификат установки. Ссылка и инструкция - в разделе
   [Эта установка](#installation) и в блоке «Документация и полезные ссылки» на «Обзоре».
3. Войдите и задайте свой пароль: с разовым паролем портал пускает только на смену пароля.
4. Заполните [профиль](/profile): имя, e-mail, Telegram - по ним вас найдут коллеги.

## Разделы меню

| Раздел | Что там |
|---|---|
| **Обзор** | Стартовая страница: состояние стендов, задачи, последние прогоны, баги, полезные ссылки |
| **Прогоны** | Все прогоны тестов с итогами, отчётами и Allure |
| **Стенды** | Карточки стендов: адреса, доступы, что развёрнуто, состояние, действия |
| **Задачи** | Очередь работы агентов: прогоны и действия со стендами, живой лог |
| **Баги** | Найденные баги с важностью и статусом |
| **Статистика** | Доля прошедших тестов, тренд, чаще всего падающие и нестабильные тесты |
| **Сводки** | Датированные отчеты по модулям и проектам, покрытие, оценка готовности и автономные презентации |
| **Справка** | Этот раздел |
| **Пользователи** | Только для администратора |

Ваше имя в правом верхнем углу ведёт в профиль.
