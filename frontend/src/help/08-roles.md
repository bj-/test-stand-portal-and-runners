# Роли и права

| Что | Только просмотр | Разработчик | Тестировщик | Администратор |
|---|:-:|:-:|:-:|:-:|
| Смотреть прогоны, отчёты, баги, статистику, стенды | ✓ | ✓ | ✓ | ✓ |
| Видеть доступы к базам стендов | - | ✓ | ✓ | ✓ |
| Запускать прогоны | - | ✓ | ✓ | ✓ |
| Запускать разрушающие тесты | - | - | ✓ | ✓ |
| Отменять задачи | - | свои | любые | любые |
| Состояние и логи стенда | - | ✓ | ✓ | ✓ |
| Пересобрать, перезапустить, засеять, сбросить стенд | - | - | ✓ | ✓ |
| Обновить индекс результатов | - | - | ✓ | ✓ |
| Пользователи: добавлять, менять роль, сбрасывать пароль, отключать | - | - | - | ✓ |

Кроме людей, к порталу обращаются по токенам: **агент** (забирает и выполняет задачи) и **ИИ-ассистент** (читает данные
без закрытых частей багов и отчётов).
