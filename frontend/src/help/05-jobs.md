# Задачи и агенты

Портал сам ничего не запускает: он ставит **задачу** в очередь, а **агент** - программа на машине со стендами или
исполнителями - забирает подходящую задачу, выполняет и присылает живой лог и итог.

## Состояния задачи

| Состояние | Значение |
|---|---|
| ○ в очереди | Ждёт свободного агента или освобождения стенда |
| ▶ выполняется | Агент работает, лог обновляется на странице задачи |
| ✓ завершена | Готово. Для прогона - ссылка на результаты; упавшие тесты - обычный итог прогона, не сбой |
| ✕ сбой | Задача не выполнена: причина - в сообщении и логе |
| – отменена | Остановлена до или во время выполнения |

## Правила очереди

- На одном стенде одновременно идёт одна «занимающая» задача: прогон, пересборка, перезапуск, засев или сброс.
  Задачи на других стендах не ждут.
- Если агент пропал во время задачи, через несколько минут она завершается сбоем, и стенд освобождается.
- **Отмена:** разработчик отменяет свои задачи, тестировщик и администратор - любые. Отмена спрашивает подтверждение:
  прерванное действие со стендом может оставить его в промежуточном состоянии.

## Пакет прогонов

В поле «Ветка тестов» выберите ветку из списка проекта. Если доступна `main`, она выбрана по умолчанию; иначе выберите ветку вручную. При смене проекта список обновляется, выбранные тесты сбрасываются. Пока список загружается, недоступен или пуст, запуск заблокирован.

На странице запуска можно выбрать до 20 наборов. Каждый набор создаёт отдельную задачу и отчёт; тест, входящий в несколько наборов, выполняется в каждом из них. Страница пакета показывает общий ход и ссылки на задачи и отчёты. Пакет можно открыть со страницы задачи или из списка задач.

При точном выборе отметьте хотя бы один тест в каждом наборе (до 500 на набор). Поиск не снимает уже выбранные тесты. Общий фильтр по названию применяется к каждому набору; пустой фильтр запускает набор целиком. Gate и разрешение разрушающих тестов учитываются для каждого набора. Отменить можно отдельную задачу. Завершение задачи не означает, что все её тесты прошли: результат проверяется в отчёте.
