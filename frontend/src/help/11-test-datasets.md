# Наборы тестовых данных

## Комплект для новых стендов

В каталоге стендов проекта откройте **Тестовые данные стендов**. Добавьте в базовый комплект нужные модули и версии наборов. При создании проекта данные модулей можно загрузить в той же форме. Ключ модуля должен совпадать с ключом `data_modules` шаблона, а формат набора с форматом его адаптера.

На шаге **Настройки** мастер показывает модули комплекта для выбранного профиля. Флажок **Установить комплект** включён по умолчанию. Снимите его для создания стенда без этого комплекта. Версии, закреплённые при создании, повторно применяются при пересборке экземпляра.

Набор хранит данные проекта в версиях и может использоваться на нескольких стендах. Откройте **Стенды**, выберите нужный стенд и нажмите **Тестовые данные**. Каталог доступен ролям портала developer, tester и admin. Это роли доступа к порталу; они не задают роли пользователей приложения в содержимом набора.

## Создать набор

1. Разверните **Создать набор или новую версию**. Загрузите **JSON-файл** или введите объект в поле **JSON данных**.
2. Для нового набора заполните **Ключ нового набора**, **Название нового набора**, **Формат нового набора** и при необходимости **Описание нового набора**. Ключ должен быть уникальным в проекте. Формат должен соответствовать формату выбранной цели стенда, например `relational-v1`.
3. Нажмите **Сохранить новый набор**. Для новой версии существующего набора сначала выберите его в поле **Набор**, затем измените JSON и нажмите **Сохранить новую версию**. Формат набора сохраняется. Developer может добавлять версии своих наборов; tester и admin — любых наборов проекта.
4. Выберите **Набор** и **Версию**. В раскрывающемся блоке JSON версии можно посмотреть и скачать содержимое или скопировать его в редактор.

Сохранение не изменяет данные стенда. Версии неизменяемы: изменение создаёт новую версию, а ранее подключённые версии не переключаются автоматически.

## Пример relational-v1

Это пример структуры для реляционной цели. Замените имена таблиц и колонок на существующие в своей схеме, а `key` — на её полный первичный или подходящий уникальный ключ. При связанных таблицах сначала указывайте родительскую, затем дочернюю. Используйте только скалярные значения JSON: строки, конечные числа, `true`, `false` или `null`.

```json
{
  "tables": [
    {"table": "customers", "key": ["id"], "rows": [
      {"id": -101, "name": "Example"}
    ]},
    {"table": "orders", "key": ["id"], "rows": [
      {"id": -201, "customer_id": -101, "total": 12.5}
    ]}
  ]
}
```

В корне должен быть объект. Лимит файла и исходного текста редактора — 2 МиБ в UTF-8, включая пробелы. `NaN` и `Infinity` недопустимы. Формат описывает данные, а не произвольный SQL. Пароль, записанный обычной строкой непосредственно в поле хеша, не превращается в корректный хеш: используйте способ подготовки учётных данных, принятый в приложении.

## Применить или подключить

Выберите набор, версию и **Цель** с совместимым форматом. **Залить выбранную версию сейчас** ставит разовую задачу применения к цели; ссылка на задачу и её состояние появятся в окне. Для цели должна быть настроена возможность применения.

**Подключить выбранную версию к стенду** сохраняет подключение, не меняя данные сразу. Им управляют tester и admin. В разделе **Подключённые наборы** можно изменить и сохранить:

- **Версия** — конкретная закреплённая версия набора;
- **Включено** (`enabled`) — участвует ли подключение;
- **Автоприменение** (`auto_apply`) — применять ли его при развёртывании, засеве и сбросе;
- **Порядок** (`position`) — целое число для порядка выполнения, меньшие значения идут раньше.

Для автоматического применения должны быть включены оба флажка. Подключите тот же общий набор отдельно к другим стендам и выберите для каждого нужную версию и цель. Новая версия не меняет существующие подключения. **Отсоединить набор** удаляет подключение, но оставляет уже загруженные данные в базе.

Чтобы увидеть фактические данные, выберите цель, раскройте **Посмотреть фактические данные**, введите запрос JSON в формате её адаптера и нажмите **Запросить данные выбранной цели**. Результат появляется после выполнения задачи.

## Открыть опубликованный пример

На нужном стенде откройте **Тестовые данные** → **Наборы проекта**, найдите опубликованный демонстрационный набор по сообщённому названию, выберите его и версию. Раскройте **JSON версии**, чтобы посмотреть содержимое или скачать его. Чтобы использовать пример как основу, нажмите **Скопировать в редактор**, измените нужные значения и сохраните новый набор с отдельным ключом. Для применения дополнительно выберите совместимую цель.
