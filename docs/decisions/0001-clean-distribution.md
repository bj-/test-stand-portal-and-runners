# 0001. Чистый репозиторий переносимой поставки

- Статус: принято владельцем.
- Дата: 2026-11-18.

## Контекст

Инструменты установки и runners нужны разным проектам. Существующие репозитории
установок смешивают инфраструктурные адаптеры с частными настройками и историей.

## Решение

Переносимый код и нейтральные примеры создаются в новом репозитории
`test-stand-portal-and-runners` с чистой историей. Существующие частные установки
остаются отдельно; их история сюда не переносится. Лицензия нового репозитория —
Apache-2.0, выбранная владельцем при создании.

Портал подключается как отдельный исходный проект. Внешний каталог установки
содержит настройки и рабочие данные. Установка зависимостей входит в поставку;
для прохождения документированного сценария LLM не нужен.

## Последствия

Новая поставка развивается постепенно: установщики и нейтральный пример,
затем шаблон реального приложения, ветки, UI создания стендов и агенты.
Новая лицензия не меняет лицензию отдельно подключаемого портала или приложений.
Публикация переносимого кода не открывает частные установки.
