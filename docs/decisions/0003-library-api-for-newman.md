# 0003. Test-Library для Newman через HTTPS API

- Статус принят
- Дата 2026-11-24
- Участники bj и Codex

## Контекст

При подготовке прогонов агент раньше мог обновлять клон Test-Library и монтировать
его в контейнер Newman. Рабочие установки уже поддерживают выборочную загрузку
из API библиотеки. Владелец стенда запросил одинаковый порядок для всех установок.

## Решение

Newman получает метаданные, профили и тестовые значения через HTTPS API
Test-Library по отдельному ключу организации клиента. Агент проверяет настройки
при получении задания и передает ключ движку через защищенный файл или окружение.
Движок записывает источник и ревизии ресурсов в манифест прогона.

## Последствия

На установке нужны сетевой доступ к API, ключ с runtime-правами и совместимый
движок от версии 0.12.0. Ошибка конфигурации или API завершает конкретный прогон.
Прежний клон Test-Library можно удалить после проверки манифеста и отчета.
