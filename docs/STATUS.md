# Состояние проекта

## Цель

Единый открытый комплект портала, стендов и исполнителей под Apache-2.0.
Состав и границы конфигурации описаны в [ADR 0002](decisions/0002-unified-platform.md).
[Развёртывание](../DEPLOY.md) доступно из одного checkout.

## Версия

Подготовка v0.3.0: сводки тестирования проектов поверх возможностей v0.2.2.

## Готово

- Сводки тестирования: последняя сводка на обзоре, история по проекту,
  Markdown и скачивание автономного HTML. Файловый формат работает и без
  клона результатов. [ADR 0004](decisions/0004-project-test-summaries.md).
- Справка по подготовке, оценке покрытия и публикации сводки для любого проекта.
- Портал с PostgreSQL, мастер стендов и реестр шаблонов.
- Агент, Compose executor и повтор сборки по выбранным SHA.
- Удаление экземпляра убирает его ресурсы Compose, образы сборки и временные
  файлы запуска. Карточка, история сборок и отчеты остаются доступны.
- Временные стенды автоматически передаются на удаление после окончания
  выбранной даты. Проверка сроков проходит в полночь по времени хоста портала.
  [Правила автоудаления](stand-management-api.md#удаление).
- Комплекты данных по модулям, окружения Newman, состояние, логи и перезапуск стендов.
- Установщики и учебный стенд с миграциями, засевом и smoke/Allure.
- Обновлятор портала и runner по выбранной ревизии Git.
- Пауза обновлений из Git через страницу администратора и API. Состояние хранится
  в установке, ручная проверка доступна на паузе. [Механизм обновлений](../updater/README.md).
- Случайный пароль администратора после первой установки.
- С версии 0.2.0 Newman получает ресурсы Test-Library по HTTPS API с ключом клиента.
  [ADR 0003](decisions/0003-library-api-for-newman.md)

## Проверка v0.3.0

Backend: 749 тестов прошли, 8 пропущены на Windows, ошибок нет.
Интерфейс: `npm ci --offline` и `npm run build` прошли.
Приемка обновления установки и публикация выполняются отдельно.
