# Состояние проекта

## Цель

Единый открытый комплект портала, стендов и исполнителей под Apache-2.0.
Состав и границы конфигурации описаны в [ADR 0002](decisions/0002-unified-platform.md).
[Развёртывание](../DEPLOY.md) доступно из одного checkout.

## Готово

- Портал с PostgreSQL, мастер стендов и реестр шаблонов.
- Агент, Compose executor и повтор сборки по выбранным SHA.
- Комплекты данных по модулям, окружения Newman, состояние, логи и перезапуск стендов.
- Установщики и учебный стенд с миграциями, засевом и smoke/Allure.
- Обновлятор портала и runner по выбранной ревизии Git.
- Случайный пароль администратора после первой установки.

## В работе

- Приёмка первого релиза из объединённого репозитория.
- Приёмка чистой установки на Windows, Ubuntu и macOS.
